Welcome to the API Reference. Here lies information about built-in *modules, globals, etc.* and their expected arguments, returns, their types, and similar stuff.

You can go to 2 different API reference categories:

* [API Reference for Sonata modules & globals (Luau)](module/index.md) - Go here if you're looking for info about a Sonata module
* [API Reference for Sonata's source & internal structure (C++)](source/index.md) - Go here if you're developing your own module, modifying source code or similar stuff
=======

The API reference has two parts:

* [**Module API (Luau)**](module/index.md): the globals and built-in `@sonata/*` libraries
  available to scripts, with every function's arguments, return values and types. Go here if
  you're writing Luau code that runs on Sonata.
* [**Source API (C++)**](source/index.md): Sonata's public C++ headers and internal structure.
  Go here if you're embedding Sonata, writing a built-in library or command, or working on
  Sonata's source code.
