# API Reference

The API reference has two parts:

* [**Module API (Luau)**](module/index.md): the globals and built-in `@sonata/*` libraries
  available to scripts, with every function's arguments, return values and types. Go here if
  you're writing Luau code that runs on Sonata.
* [**Source API (C++)**](source/index.md): Sonata's public C++ headers and internal structure.
  Go here if you're embedding Sonata, writing a built-in library or command, or working on
  Sonata's source code.
